# ML

## 담당

AI 담당자가 모델 실험, 학습, 평가, 추론 코드를 관리하는 공간입니다.

## 목적

이상행동 탐지 모델의 학습 과정과 실험 코드를 관리합니다. 실제 학습 데이터와 모델 파일은 GitHub에 업로드하지 않습니다.

## 하위 폴더

- `notebooks/`: 데이터 분석과 모델 실험 노트북
- `training/`: 모델 학습 코드
- `inference/`: 추론 로직과 후처리 코드
- `models/`: 모델 관리 정책 문서

## 추후 작성할 내용

- 데이터 전처리 방법
- 모델 학습 방법
- 평가 지표
- 실험 기록 방식
